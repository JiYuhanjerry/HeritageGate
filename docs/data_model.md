# Data model summary

The v0.1 tables remain the workflow backbone:

- `projects`
- `gate_records`
- `audit_events`

Version 0.2.0 adds normalized tables:

- `rights_holders`
- `authorization_records`
- `authorization_parties`
- `cultural_element_cards`
- `element_annotators`
- `model_runs`
- `model_run_elements`
- `expert_reviews`
- `market_tests`
- `revenue_distributions`
- `schema_metadata`

See `structured_data_model.md` for field meanings and gate mappings.
