# Submission-release module

The `export-submission-release` command prepares publication and software-release
materials. It does not upload files or create a GitHub release or Zenodo record.

## Public release materials

- `CITATION.cff`
- `codemeta.json`
- `.zenodo.json`
- `GitHub_RELEASE_NOTES.md`
- `softwarex_metadata_tables.md`
- release README and project license/docs where available
- matching wheel when available

## Editorial submission materials

- SoftwareX five-section manuscript draft;
- Highlights;
- cover-letter draft;
- CRediT author statement template;
- data-availability statement;
- generative-AI use declaration placeholder;
- release-readiness JSON and CSV;
- author-verification checklist.

## Aggregate evidence

The package includes aggregate pilot statistics and reproducibility metadata.
It deliberately excludes participant-level rows, participant codes, consent
references, consent files, identity-token hashes, source-row hashes, and raw
session evidence.

## Human verification

The authors must verify:

- title, authorship, affiliations, ORCID records, and CRediT roles;
- repository, archived release, executable, documentation, and DOI links;
- software version, license, and release date;
- ethics approval/exemption and consent wording;
- all empirical values and limitations;
- funding, competing interests, data availability, and generative-AI disclosure;
- the current SoftwareX template and submission requirements.
