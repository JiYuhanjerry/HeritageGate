# SoftwareX readiness status

HeritageGate v0.4.0 provides the technical structures needed to collect and export installation, task, usability, and workflow-comparison evidence. It also provides reproducible test, manifest, CSV, figure, and checksum outputs.

Still required before submission:

- public Git repository and tagged release;
- archived release and DOI;
- real author and support details;
- independent installation testing;
- ethics-appropriate real or controlled pilot evidence;
- verification of every evidence reference;
- final SoftwareX template manuscript;
- final license, code metadata, software metadata, CRediT, data availability, conflict, funding, and generative-AI declarations.
