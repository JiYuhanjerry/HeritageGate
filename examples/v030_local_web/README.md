# v0.3 local web and export example

This directory contains a completely synthetic demonstration generated by
HeritageGate v0.3.1.

- `demo.db`: SQLite database used by the local browser interface.
- `structured_manifest.json`: complete Gate 0–7 manifest.
- `research_bundle.zip`: portable JSON/CSV export.
- `export_metadata.json`: exporter output including SHA-256 digest.

Run the interface from the project root:

```powershell
python .\run_heritagegate.py --db .\examples\v030_local_web\demo.db web --open-browser
```

No record in this example represents a living heritage community, real
authorization, real cultural meaning, or real revenue distribution.
